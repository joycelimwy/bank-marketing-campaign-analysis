# Practical Application III: Comparing Classifiers

## Overview

This project compares several classification models to predict whether
a Portuguese bank's client will subscribe to a term deposit following a marketing campaign.

## Models

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Support Vector Machine (SVM)

## Analysis

The project evaluates baseline model performance and then uses
hyperparameter tuning and GridSearchCV to improve model performance.

## Key Finding

After tuning, Logistic Regression achieved the highest test accuracy
(89.74%) while also requiring substantially less training time than
KNN and SVC. Overall, Logistic Regression provided the best balance
of accuracy and efficiency for this dataset.
